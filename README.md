# Tic-Tac-Toe AI using Java

## Project Description
This project is a simple Tic-Tac-Toe game developed
using Java Swing GUI. It allows a human player to
play against an AI opponent.

The AI uses the Minimax Algorithm to make intelligent
decisions and select the best possible moves.

## Features
- User-friendly Graphical Interface
- Human vs AI gameplay
- Minimax Algorithm
- Automatic Winner Detection
- Draw Detection
- Restart Game Option

## Technologies Used
- Java
- Java Swing
- Minimax Algorithm

## How to Run
1. Download the project.
2. Open the project in VS Code.
3. Compile using: javac TicTacToe.java
4. Run using: java TicTacToe
